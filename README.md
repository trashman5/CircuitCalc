# CircuitCalc
Java Servlet exercise that calculates parameters of current mirror circuits.

## DesignLogicServlet
The main logic behind the calculator

## HistoryFetcherServlet
Displays a history of calculated designs stored on a server side database

## SaveDesignServlet
Push the calculated parameters to the database

## DeleteDesignServlet
Called from the HistoryFetcherServlet, it deletes an entry on the database
